# Chordoku

Веб-судоку, где вместо цифр используются музыкальные аккорды. Сайт опубликован на GitHub Pages: https://beslanchick.github.io/chordoku/.

Для MIDI откройте сайт в Chrome или Яндекс Браузере и нажмите «Подключить MIDI», затем разрешите доступ. Сайт работает по HTTPS. В Safari Web MIDI не поддерживается.

## Управление
- При новой партии можно отдельно выбрать сложность судоку и аккордов. Поле получает новую случайную раскладку с единственным решением; сложность судоку задаёт число исходных клеток.
- Для сложности аккордов доступны мажорные и минорные трезвучия, уменьшённые и увеличенные трезвучия, септаккорды и нонаккорды. Состав выбранных аккордов сохраняется при продолжении партии.
- Без sustain ноты До, Ре♭, Ре, Ми♭, Ми, Фа, Соль♭, Соль, Ля♭ выбирают блоки 1–9. При удержании педали те же ноты выбирают клетку 1–9 в активном блоке.
- Три быстрых До — Undo, три быстрых Ре — Redo, три быстрых Соль — очистить выбранную клетку. Для отличия аккорда от одиночной ноты приложение собирает MIDI-ввод в течение 220 мс.
- MIDI CC64 управляет sustain. Аккорды подсвечивают клавиши, а сам инструмент воспроизводит звук.
- Мышь доступна для поля, подсказок и действий. В правой панели есть список аккордов и счётчик заполненных клеток; наведение на аккорд подсвечивает его клавиши и заполненные им клетки.
- Повторное исполнение финального аккорда в выбранной клетке при удерживаемой педали удаляет ответ. Подсказка предлагает следующий логичный ход, не раскрывая точный ответ.
- Повторный запуск позволяет выбрать сложность судоку и аккордов отдельно; логотип расположен слева от таймера.
- Партия, таймер, кандидаты и история действий сохраняются в браузере. Старые сохранения получают случайный набор аккордов при первом открытии новой версии, не теряя ход партии.

Для локального запуска с Node.js выполните `npm run serve`, затем откройте http://localhost:4173. Подробное согласованное техническое задание находится в [SPEC.md](SPEC.md).
