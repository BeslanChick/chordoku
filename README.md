# Chordoku

Веб-судоку, где вместо цифр используются музыкальные аккорды. Сайт опубликован на GitHub Pages: https://beslanchick.github.io/chordoku/.

Для MIDI откройте сайт в Chrome или Яндекс Браузере и нажмите «Подключить MIDI», затем разрешите доступ. Сайт работает по HTTPS. В Safari Web MIDI не поддерживается.

## Управление
- В каждой новой партии выбираются 9 уникальных мажорных и минорных трезвучий. Набор сохраняется при продолжении партии.
- Без sustain ноты До, Ре♭, Ре, Ми♭, Ми, Фа, Соль♭, Соль, Ля♭ выбирают блоки 1–9. При удержании педали те же ноты выбирают клетку 1–9 в активном блоке.
- Три быстрых До — Undo, три быстрых Ре — Redo. Для отличия аккорда от одиночной ноты приложение собирает MIDI-ввод в течение 220 мс.
- MIDI CC64 управляет sustain. Аккорды подсвечивают клавиши, а сам инструмент воспроизводит звук.
- Мышь доступна для поля, подсказок и действий. В правой панели есть список аккордов и счётчик заполненных клеток; наведение на аккорд подсвечивает его ноты оранжевым.
- Партия, таймер, кандидаты и история действий сохраняются в браузере. Старые сохранения получают случайный набор аккордов при первом открытии новой версии, не теряя ход партии.

Для локального запуска с Node.js выполните `npm run serve`, затем откройте http://localhost:4173. Подробное согласованное техническое задание находится в [SPEC.md](SPEC.md).
